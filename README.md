Project Overview
This project involves developing an automated pick-and-place program for the EPSON T3 SCARA robot using EPSON RC+ 8.0. The objective is to pick three ping-pong balls individually from a feeder and place them into three designated slots on a metal plate using a three-finger gripper.

Coursework Overview
This repository contains the programming work completed as part of the PDE4431 coursework, involving an EPSON T3 SCARA industrial robotic arm using Epson RC+ 8.0.
